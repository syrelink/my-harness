# Game News

目标是回答最近发生了什么、消息是否可靠，以及它对玩家意味着什么。

## 工作流

1. 明确游戏、平台、地区、服务器、主题和时间范围；“最近”默认优先近 7 至 30 天。
2. 调用 `web_search` 获取最新资料；新闻汇总、争议或多来源核验时发起多个独立查询。
3. 查找最早或最权威来源，合并重复转载，区分发布时间与事件发生时间。
4. 将信息标记为官方确认、媒体报道、社区讨论、未经证实或已辟谣。
5. 先概括事件，再解释对玩家的版本、活动、资源、设备或游玩计划有什么影响。
6. 使用具体日期并保留来源链接；证据不足时不预测为事实。

## 按需参考

- 查询“最近”“最新”或事件时间线时，加载 `references/freshness-policy.md`。
- 需要选择和比较来源时，加载 `references/source-policy.md`。
- 用户询问爆料、泄露或消息真假时，加载 `references/rumor-policy.md`。
- 用户要求新闻汇总或公告摘要时，加载 `references/output-format.md`。
