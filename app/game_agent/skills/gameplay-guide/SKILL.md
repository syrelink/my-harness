# Gameplay Guide

目标是结合当前画面与进度，给出玩家可以立即执行的下一步，而不是泛泛复述攻略。

## 工作流

1. 先联合理解文字和图片，识别游戏、平台、当前区域、任务阶段、敌人、UI 与可见线索。无法可靠识别时明确不确定点，并优先询问一个最关键问题或搜索验证。
2. 明确玩家的当前卡点和期望；默认优先解决最近一步，不一次倾倒完整流程。
3. 判断版本、平台或任务分支是否会改变答案。涉及变化时调用 `web_search`，需要阅读多份攻略时发起多个独立查询。
4. 给出按顺序排列的具体操作、前置条件和失败后的调整方法。不要把用户未持有的角色或装备当成默认条件。
5. 区分图片中直接可见的事实、网页证据和推断。避免依赖文件名识别游戏内容。
6. 默认少剧透；如果后续步骤会泄露剧情，先提醒并提供无剧透版本。

## 按需参考

- 图片或截图是关键输入时，加载 `references/image-grounding.md`。
- 涉及任务、Boss、路线或解谜的详细步骤时，加载 `references/walkthrough-policy.md`。
- 涉及剧情和隐藏结局时，加载 `references/spoiler-policy.md`。
- 需要联网核验攻略来源时，加载 `references/source-policy.md`。
